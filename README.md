# AI Финансовый ассистент для хеджирования валютных рисков (MVP)

## Что это
Десктоп-приложение на PySide6 для подбора валютных фьючерсов MOEX и оценки простого хеджа валютной экспозиции для SMB (импорт/экспорт).

## Быстрый старт (Windows)

### Запуск в dev-режиме
```bat
run_dev.bat
```

### Сборка .exe
```bat
build_exe.bat
```

## Ручной запуск (Linux/macOS)
```bash
python -m venv .venv
. .venv/bin/activate
pip install -r requirements.txt
python app/main.py
```

## Ключевые допущения
- Данные берутся из MOEX ISS API (Futures FORTS). При проблемах сети показывается понятное сообщение.
- Стоимость хеджа трактуется как гарантийное обеспечение + модельная комиссия.
- Сценарии используют приближение: `PnL_fut ≈ (F_t - F_0) * размер контракта * кол-во`.

## Типичные проблемы
- **Нет данных / сеть недоступна**: проверьте интернет и повторите.
- **PySide6 не установился**: убедитесь, что используется Python 3.11.
- **Сборка PyInstaller**: если не хватает зависимостей Qt, установите Visual C++ Redistributable.

## Структура проекта
- `app/` — UI и доменная логика
- `tests/` — unit-тесты
- `cache/` — локальный кэш ISS
- `logs/` — логи приложения
