# AI Финансовый ассистент для хеджирования валютных рисков

Демонстрационный дашборд для малого и среднего бизнеса, работающего с импортом и экспортом. Приложение помогает подобрать наиболее подходящие фьючерсные инструменты Московской биржи под заданные параметры компании и рассчитывает ориентировочную стоимость хеджирования.

## Что делает приложение
- Позволяет выбрать отрасль и валюту хеджирования из списка, актуального для фьючерсных инструментов Мосбиржи.
- Принимает объем валюты, сроки покупки и продажи.
- Подбирает ближайшие инструменты по дате экспирации и считает число контрактов, покрытие и оценку затрат.
- Отображает несколько вариантов на разных инструментах для сравнения.

## Запуск локально
1. Убедитесь, что установлен Python 3.10+.
2. Запустите приложение:

```bash
python app.py
```

## Сборка в `.exe`
Для упаковки в исполняемый файл можно использовать `pyinstaller`:

```bash
pip install pyinstaller
pyinstaller --onefile --windowed app.py
```

Готовый `.exe` появится в каталоге `dist/`.
